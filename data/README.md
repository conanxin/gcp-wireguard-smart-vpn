# Data

This directory contains the generated routing and DNS datasets used by the Windows SMART split-routing layer.

The checked-in files are verified snapshots generated by the scripts under `windows/`.

A fresh clone can therefore use `smart-on.ps1` immediately without first downloading upstream datasets.

## Updating the datasets

Preview updates without writing files:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\windows\update-cn-ip.ps1 -DryRun
powershell.exe -ExecutionPolicy Bypass -File .\windows\update-cn-domains.ps1 -DryRun
```

Generate updated snapshots:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\windows\update-cn-ip.ps1
powershell.exe -ExecutionPolicy Bypass -File .\windows\update-cn-domains.ps1
```

The updater scripts validate upstream data before writing output.

Checks include:

- upstream checksum verification where available
- source record-count consistency
- CIDR alignment validation
- IPv4 address conservation
- duplicate detection
- unsupported domain-rule classification
- generic-TLD risk detection
- direct/VPN semantic sanity tests

## Runtime use

The Windows SMART scripts use:

```text
data\cn-ipv4-cidrs.txt
data\cn-nrpt-namespaces.txt
```

The resulting routing model is:

```text
CN IPv4
    -> physical gateway
    -> direct connection

CN domains
    -> Windows NRPT
    -> China DNS

Other IPv4
    -> WireGuard

Other DNS
    -> WireGuard private DNS
```

## Editing

Do not manually edit generated dataset files.

If generator behavior needs to change:

1. modify the corresponding script under `windows/`
2. run it in `-DryRun` mode
3. generate the new dataset
4. inspect the resulting differences
5. update the checked-in snapshot
